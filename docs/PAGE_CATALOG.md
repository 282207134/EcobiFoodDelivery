特殊状态说明：

- Focus/Typing 画板使用真实输入框焦点和系统键盘；PNG 保留焦点，不包含系统单独绘制的键盘。
- Delete 使用左滑删除和删除入口；Popup Delete 为可确认/取消的弹窗。
- Voucher Details 以独立详情页承载原稿详情面板内容。Filter 使用独立页面承载原稿筛选面板，控件可操作。
- 两个扫码结果都保留原稿图像。识别、闪光灯和相机权限界面为演示。
- 两个 Saved 画板的商店列表复用；预览入口额外展示操作菜单。
- About 和 Screen Gallery 为便于验收新增的辅助页。
