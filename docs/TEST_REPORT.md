# 验证记录

验证日期：2026-11-01（Asia/Tokyo）。

## 环境

- Windows 开发环境，Flutter 3.47.7 stable / Dart 3.13.5。
- Android 15 / API 35，x86_64 独立模拟器 `ecobi_review`。
- 截图分辨率 750 × 1624，逻辑屏幕 375 × 812，2 倍像素密度。
- 紧凑布局额外验证 320 × 690。

## 结果

| 检查 | 结果 | 验证内容 |

| `flutter analyze` | 通过，无问题 | 应用代码、单元测试、截图测试和驱动 |
| `flutter test` | 5 项通过 | 下述业务及界面测试 |

五项测试：

1. 购物车单价、数量和优惠计算；保存/恢复订单；重购、减量和移除。
2. 不合法手机号显示校验错误；合法手机号进入 OTP。
3. 所有设计路由在 375 × 812 与 320 × 690 两种尺寸中正常布局，无渲染异常。
4. 从商品详情添加购物车、结算到订单成功，校验创建订单且清空购物车。
5. 左滑删除后确认移除商品；搜索不存在的关键词显示空结果。

## 截图过程

`integration_test/screenshots_test.dart` 枚举 `app.dart` 的路由表，在 Android 模拟器中构建真实页面并检查渲染异常。截图前预加载所有图片，避免设备较慢时首帧插画缺失；额外补拍登录密码页，确认系统键盘收起后内容完整。每张 PNG 立即写入应用私有目录，结束时由测试驱动导出到项目。PNG 只包含 Flutter 绘制区域，系统单独绘制的键盘不在图中。

`docs/screenshots/` 包含 50 张运行图；`docs/reference/` 包含 49 张 Pixso 原稿。`PAGE_CATALOG.md` 逐画板映射二者。重复原稿共用页面图，输入焦点和空状态有独立预览路由。

## 安装包

`dist/Ecobi-1.0.0-android-arm64.apk`，约 19.7 MB。正式发布前需要替换开发签名。包内入口为正常应用，不包含截图测试入口。首次启动进入引导；已保存的演示登录状态可直接进入首页。

## 已知边界

- 已验证 Android；iOS 工程和品牌图标已准备，但未在 Windows 上构建/测试 iOS。
- 登录、支付、优惠资格、外部账号、邀请、联系配送员、定位与真实扫码未连接服务；具体演示行为见 README 和 ARCHITECTURE。
- 地图及扫码背景来自原稿，为静态素材。
- 键盘外观、系统安全区和滚动行为跟随运行设备；原稿长页面在截图中展示设备当前可视区。
- 优惠券详情和筛选采用独立页面承载原稿面板内容。原稿固定金额与不一致价格已改为统一商品目录的实时计算。
